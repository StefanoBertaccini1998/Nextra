# ADR 0001 — MVP Scope (Nextra)
Data: 2025-10-12 — Stato: Approvato

## Contesto
MVP in 1–2 settimane per ordini di divani artigianali e materiali chiave.

## Decisione (IN)
- Ordini con configurazione base (modello, tessuto/colore, piedi)
- Calcolo materiali v1 (tessuto, fusto, piedi)
- Magazzino light (stock, ubicazioni, terzista)
- Piano settimanale (aggregazioni tagli/fusti)
- Checklist QC pre-evasione

## Decisione (OUT, post-MVP)
- App mobile, integrazione SDI completa, reportistica avanzata

## Conseguenze
Consegna rapida; feature avanzate in iterazioni successive.
